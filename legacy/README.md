# Legacy: Uniblox e-commerce store (archived)

This folder holds the original 2023 take-home that this repository started as: a FastAPI +
SQLAlchemy backend with products, users, a cart, checkout with an "every nth order gets a 10%
code" discount rule, and admin statistics. It is kept for reference only. It is not maintained,
has no tests, and is not part of the Loom build, lint or test runs. See the repository root
README for Loom.
